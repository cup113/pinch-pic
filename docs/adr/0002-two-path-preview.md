# 双路径架构：专职预览 Worker + 无状态编码 Worker 池

"拖滑块实时看到糊不糊"无法靠全图编码实现（AVIF 一张数秒）。决定：
一个专职预览 Worker 持有选中作业的解码位图，只对可见视口区域（按输出比例反算到源图）
过一遍与正式输出完全相同的管线（重采样→编码→解码→上屏），150ms 防抖；
全量编码由无状态 Worker 池（min(硬件线程-1, 4)）执行，每个任务独立"解码→编码"，
不做位图缓存，避免作业-Worker 亲和与内存回收复杂度。

## Consequences

- 全量编码每次重跑多付一次解码（12MP 约 150ms），相对编码耗时可接受
- 裁剪预览的诚实性是纪律：任何参数管线改动必须同时作用于两条路径
- 预览 Worker 只缓存当前选中作业，切换选中项即换源
